# Причинный анализ факторов доходности IMOEX

Данный репозиторий содержит материалы к моей курсовой работе, посвящённой анализу факторов, влияющих на доходность Индекса Московской биржи (IMOEX).

В репозитории представлены:

* код исследования в Google Colab;
* подготовка и обработка данных;
* описательный и статистический анализ;
* построение базовых моделей;
* оценка причинных эффектов с помощью Double Machine Learning;
* анализ гетерогенных эффектов;
* визуализация результатов;
* интерактивный сайт с причинным графом.

## Используемые технологии

* Python;
* Pandas;
* NumPy;
* Matplotlib;
* Seaborn;
* Scikit-learn;
* EconML;
* PyVis;
* HTML;
* CSS;
* JavaScript.

## Структура репозитория

* `код_курсовая_Солохненко.ipynb` — основной код исследования;
* `index.html`, `styles.css`, `script.js` — интерактивный сайт с причинным графом;
* `README.md` — описание проекта.

## Результаты

В ходе исследования было получено, что нефтяной фактор оказывает положительное влияние на доходность индекса IMOEX, тогда как рост курса USD/RUB связан с её снижением. Также было показано, что влияние факторов может меняться в разные периоды времени.

Для более наглядного представления результатов был разработан небольшой сайт с интерактивным причинным графом, опубликованный с помощью GitHub Pages.
